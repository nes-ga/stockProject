## 문서 관리 원칙

- 현재 코드 기준의 전체 구조는 `project-overview-2026-04-27.md`에 업데이트한다.
- 기능별 상세 정책은 전용 문서에 둔다.
- 사용자에게 보이는 문구, API, 데이터 저장 구조가 바뀌면 문서도 함께 갱신한다.
- 깨진 한글 문서는 새 UTF-8 문서로 대체하거나, 수정 시 전체 문단 단위로 재작성한다.
