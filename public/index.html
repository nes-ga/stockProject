뉴스 기사

시장 전반 뉴스와 관심 종목 관련 기사를 모아볼 수 있도록 준비한 탭입니다.

준비 중

여기에 시장 뉴스, 종목 뉴스, 키워드 검색, 기사 카드 레이아웃을 붙일 수 있게 기본 탭을 먼저 열어뒀습니다.

다음 단계에서는 뉴스 수집 API 또는 RSS/포털 기사 목록을 연결하면 됩니다.

지수 및 관심 자산
